# Koi Knight look-around preview

A web free-cam build of the starting area, for looking around on a phone or desktop. This is a preview, not the game itself.

- On a phone: drag the right side of the screen to look, use the left joystick to fly, and the Up / Down / speed buttons on the right.
- On a computer: WASD to fly, Q/E or Ctrl/Space for down/up, Shift for a burst, left-drag on the right side to look.
